# MineForge · 采矿工程知识平台

以《采矿学》（第 2 版，王青主编）为教材依据的 15 种采矿方法三维教学模型与知识库。

## 特性

- **15 种采矿方法 · 程序化三维模型**：按教材校核的 Three.js 场景，覆盖 101 道开拓、采准、切割、回采和采场处理工序
- **工序滚动演示**：滚到模型区后模型吸顶停住，右侧工序卡随页面下滑逐级驱动模型变化；点击工序卡可跳步，画布左上显示当前工序
- **左右分栏排版**：模型与播放器吸顶固定在左，工序卡在右侧滚动
- **剖面视图**：等轴测 / 纵剖 / 横剖 / 细部四种预设视角，几何剖切示意配合查看器裁剪平面
- **图层显隐**：矿体 / 围岩 / 矿柱 / 巷道 / 出矿系统等按受控词表分组
- **教材参数出处**：构筑物信息记录教材小节和图号，页面参数表提供对应参考值；场景采用教学示意比例
- **知识检索**：构建期生成 778 条静态索引，覆盖方法正文小节（328）、参数与公式（301）、规范条文、术语、文献与图解，支持按类型筛选并直达小节/参数行/条文锚点
- **资料中心**：术语、公式与参数、工程图、参考文献、标准与规范、推荐教材六类；53 条文献全部结构化（教材版次/章节页码/ISBN、期刊卷期页），未摘原文的条文显式标注「未摘原文」

## 技术栈

Astro 5 · Tailwind CSS 4 · Three.js 0.187 · TypeScript · MDX

## 构建

```bash
npm install
npm run dev      # 开发服务器 http://localhost:4321
npm run build    # 产出 dist/（纯静态，可直接部署到任意静态托管）
npm run preview  # 本地预览构建产物
```

`dev`/`build` 前会自动执行 `scripts/extract-method-sections.mjs`，从 MDX 抽取方法小节标题生成检索索引（`src/data/method-sections.json`）；也可单独运行 `npm run sections`。

## 部署

`dist/` 为全自包含静态站点（系统字体栈、公式构建期渲染、无外部引用），可直接部署到 Cloudflare Pages / Vercel / Netlify / GitHub Pages / 任意 OSS 静态托管。

- 构建命令：`npm run build`
- 输出目录：`dist`

## 内容依据

- 《采矿学》（第 2 版），王青、任凤玉主编，冶金工业出版社 —— 第 10 章崩落采矿法（p220-276）、第 11 章空场采矿法（p277-307）、第 12 章充填采矿法（p308-331），逐页精读核对
- 全部三维模型按工作区教材文字与图例核对，构筑物信息标注教材小节和图号。阶段矿房采用垂直深孔方案，单层崩落采用直线长壁方案，分段充填采用分段空场嗣后充填方案。


## 2026-11-25 模型接入更新

15 种模型通过 `src/lib/models/registry.ts` 接入现有查看器。校核后的场景布置在 `src/lib/models/reviewed/`，`reviewed.ts` 负责工序切换、图层、剖切、构筑物信息和矿料流动画。暖褐、赤陶及低饱和绿材质从 `src/styles/tokens.css` 读取。详情页继续使用原来的工序滚动、播放、进度、视角、图层与拾取控件。

`npm test` 核验 15 种模型、101 道工序及查看器数据契约。更新模型说明后，运行 `node scripts/gen-model-data.mjs` 同步方法数据，再执行 `npm run build`。根目录的 `site/` 由生成的 `dist/` 更新。
