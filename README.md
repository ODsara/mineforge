# MineForge · 采矿工程知识平台

以《采矿学》（第 2 版，王青主编）为教材依据的 15 种采矿方法三维教学模型与知识库。

## 特性

- **15 种采矿方法 · 程序化三维模型**：Three.js 参数化生成（无模型文件下载），单法最高 7220 三角形，全站合计约 52000
- **工艺阶段滚动演示**：模型随页面下滑按「采准 → 切割 → 回采 → 出矿/放矿 → 管理」逐步推进，黑色关键帧标题驱动阶段切换
- **左右分栏排版**：模型吸顶居中（左），关键帧文字滚动（右）
- **剖面视图**：等轴测 / 纵剖 / 横剖 / 细部四种预设视角，剖面为生成阶段几何剔除（无布尔运算）
- **图层显隐**：矿体 / 围岩 / 矿柱 / 巷道 / 出矿系统等按受控词表分组
- **教材参数出处**：每个模型的 PARAMS 逐项标注书页出处，页面参数表逐条对应

## 技术栈

Astro 5 · Tailwind CSS 4 · Three.js 0.187 · TypeScript · MDX

## 构建

```bash
npm install
npm run dev      # 开发服务器 http://localhost:4321
npm run build    # 产出 dist/（纯静态，可直接部署到任意静态托管）
npm run preview  # 本地预览构建产物
```

## 部署

`dist/` 为全自包含静态站点（系统字体栈、公式构建期渲染、无外部引用），可直接部署到 Cloudflare Pages / Vercel / Netlify / GitHub Pages / 任意 OSS 静态托管。

- 构建命令：`npm run build`
- 输出目录：`dist`

## 内容依据

- 《采矿学》（第 2 版），王青主编，东北大学出版社 —— 第 10 章崩落采矿法（p220-276）、第 11 章空场采矿法（p277-307）、第 12 章充填采矿法（p308-331），逐页精读核对
- 全部三维模型为按教材文字描述重建的教学示意（不复制教材插图），模型参数标注书页出处
