MineForge · 纯净版（2026-11-25）

一、目录说明
- site/：当前构建的完整静态站，44 个页面、15 种采矿方法、816 条检索索引。
- source/：纯净源码（Astro 5 + Tailwind 4 + Three.js），已剔除 node_modules、.git、.audit、.design、.astro、dist 和临时日志。
- 启动演示.bat / serve.ps1：本地静态服务，双击即可浏览。
- 版本说明.md：构建来源、剔除项与验收记录。

二、直接看演示
1. 双击“启动演示.bat”。
2. 浏览器会自动打开 http://127.0.0.1:8090/；若端口被占用，会自动改用 8091-8100，以黑色窗口显示的地址为准。
3. 保持黑色窗口开启，关闭窗口即停止；全程离线，不需要 Node、Python 或联网。
4. 不要直接双击 site 里的 html 文件，否则样式和三维模型会因路径与浏览器安全限制而加载失败。

三、继续开发
1. 进入 source 目录，执行 npm install 安装依赖。
2. npm run dev 启动开发服务器（默认 http://localhost:4321）。
3. npm run build 生成 dist；如需更新演示站，把 dist 的内容覆盖到上一级 site 目录即可。
4. source 不含 node_modules，首次安装依赖需要联网；已构建的 site 始终可离线运行。

四、三维演示操作
- 滚到方法页的三维模型区后，模型与播放器会吸顶停住，右侧工序卡继续下滑，模型随当前工序变化。
- 点击右侧任意工序卡可直接跳到该工序；画布左上角显示当前阶段、序号和工序名。
- 桌面宽度低于 768px 时自动切换为上下堆叠布局，以保证窄屏可读性。
